Author: Joseph Hook

Assisted Reproduction Calculator:

An application with a user interface that utilizes a full data pipeline to import a dataset, cleans it, transforms useful attributes then applies a linear regression model to output data to determine the expected number of cycles that need to be performed to result in a live birth.


Frameworks used:
-Python
-SciPy
-Matplotlib
-Seaborn
-Pandas
-Flask
-SQL
-SciKit Learn
